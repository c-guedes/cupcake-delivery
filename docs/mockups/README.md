## Critérios de validação

As telas finais apresentam apenas fluxos existentes: autenticação, cadastro de cliente ou entregador, catálogo com busca/ordenação, carrinho, endereço e criação de pedido, acompanhamento de pedidos, administração e entrega. A execução técnica está registrada nas [capturas de evidência](../pit_ii/evidencias/README.md).
